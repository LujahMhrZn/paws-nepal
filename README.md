
## **Project: PAWS Nepal – Dog Adoption Website**

**Semester:** 2nd Semester – BCSIT
**Technologies:** HTML, CSS, JavaScript (Static Website)

**Description:**
PAWS Nepal is a static, responsive dog adoption website designed to promote animal welfare and make it easier for people to adopt dogs. The site provides detailed information about available dogs, adoption guidelines, and contact details for potential adopters.

**Key Features:**

* **Home Page:** Warm, welcoming introduction to PAWS Nepal and its mission.
* **Adoption Gallery:** Showcases adoptable dogs with pictures, breed information, and short descriptions.
* **Adoption Form:** Simple HTML form allowing interested adopters to send their details.
* **Responsive Design:** Optimized for desktop, tablet, and mobile viewing using CSS media queries.
* **Interactive Elements:** JavaScript-based image hover effects, form validation, and navigation enhancements.

**Learning Outcomes:**

* Improved skills in semantic HTML structure and CSS styling.
* Gained hands-on experience with JavaScript DOM manipulation.
* Learned to create a fully responsive static site layout.
* Understood the fundamentals of web design accessibility and user experience.
